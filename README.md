# AimTester

**喵准测试** - 一个用 Python + Pygame 实现的鼠标瞄准训练小游戏

## 功能
- 60秒限时挑战模式
- 点击移动的红色靶子得分
- 简单、流畅、可扩展
- 支持中文显示

## 如何运行
1. 克隆仓库
   ```bash
git clone https://github.com/Cn0f1cd/AimTester.git
cd AimTester
```

2. 安装依赖
   ```bash
pip install -r requirements.txt
```

3. 运行游戏
   ```bash
python main.py
```

## 操作说明
- **鼠标左键** 点击瞄准目标
- **R 键** 游戏结束后重新开始
